# 能力与边界

| 资源 / 能力 | 已实现 | 边界 |
|---|---|---|
| 认证 | Bearer、Canvas Cookie、IAM SSO/密码兜底、身份校验、登录互斥和冷却 | 验证码或增强认证须本人处理；不保证永久会话 |
| 课程 | 完整分页发现新可见课程、课程信息变化 | 无法总能区分新发布和新加入选课；历史观察范围可配置 |
| 作业与测验 | 新任务、正文和日期变化；due/lock/unlock 独立保存 | 以本人服务端有效日期为准，不从全班 all_dates 猜测 |
| 本人提交与成绩 | 提交、重做、可见成绩发布与改分、零分 | 不读取其他学生或教师尚未开放的信息 |
| 评论与评分量表 | 评论 ID/内容去重、排除本人评论、rubric 变化 | 非空真实数据覆盖由健康页逐范围标记 |
| 公告 | 正文及附件元数据变化 | 不自动获取外链和下载附件 |
| 文件与文件夹 | 新文件、名称/大小/时间/目录变化、完整分页 | 不逐字节比较文件内容 |
| 站内信与讨论 | 本人对话、主题、回复、嵌套分页 | 不自动标已读，不发送回复 |
| 模块与页面 | 模块条目、顺序、可读页面正文 | 无权限/不可用页面明确报错；不保证任意页面像素变化都可检测 |
| 日历和计划 | 日历、计划表、个人待办 | 计划表有明确滚动观察窗口 |
| 提醒 | 全局/课程/任务覆盖、静默、摘要、暂缓、个人标记、持久补偿 | 不从非结构化正文自动猜日期；停机断网影响发现延迟 |
| 邮件 | 官方风格 HTML+纯文本、附件/反馈入口、文件源时间、变化详情、时间与规则、可靠 outbox | SMTP 不保证端到端 exactly-once；不支持邮件回复回写 |
| 运维 | SQLite WAL / PostgreSQL、独立 web/worker、备份、健康页 | 学校权限限制及多因素认证不能由本服务消除 |

验证等级区分 `observed_nonempty_on_tongji`、`observed_empty_on_tongji` 与 `tested_with_synthetic_fixture`。真实空响应只证明接口正常接受请求，不证明非空对象已全部实测。

未接入：小组、互评、预约、LTI、任意 GraphQL、官方 iOS App、课程首页/教学大纲/导航菜单的全面变化监控。清单资源缺失先保留快照并标记待确认，不武断认定老师删除。
