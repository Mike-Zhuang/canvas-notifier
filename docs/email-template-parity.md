# 邮件模板对照

参考固定 Canvas LMS commit `1c9f0bb8013ed69c4f2efe11fd483025469b7e6c` 的 `app/messages/`：

| 上游模板 | 保留的可见信息 | 本服务补充 |
|---|---|---|
| `assignment_created.email.*` / `assignment_changed.email.*` | 课程、作业名称、变更说明、截止或未设日期、查看入口 | 完整任务说明、停止提交/开放时间、提交状态、规则说明 |
| `upcoming_assignment_alert.email.*` | 任务、正式截止、查看入口 | 剩余时间、停止提交提醒、最近同步与补偿说明 |
| `assignment_graded.email.*` | 课程、作业标题、成绩已可见说明、作业入口 | 成绩变化前后值（受隐私开关控制）、满分、提交状态、同步时间 |
| `assignment_due_date_changed.email.*` | 课程、任务、调整后的截止或未设置日期 | 调整前后对比、停止提交/开放时间、重新生成提醒计划 |
| `assignment_submitted.email.*` | 提交说明、对应任务/提交入口 | 最近同步、提交时间、重做和豁免状态 |
| `new_announcement.email.*` | 标题、正文、简单格式与表格、附件名称/大小/入口 | 发现时间、通知规则、管理入口 |
| `new_file_added.email.*` | 文件名、文件大小、课程、文件入口 | 文件变更详情、摘要内保留每一项信息 |
| `submission_comment.email.*` | 可见作者、反馈正文、附件及查看入口 | 评论更新说明、同步与发现时间、规则来源 |

在 API 实际可见和用户隐私设置允许的范围内保留对应信息；无法读取的信息不编造。独立 Jinja2 HTML/纯文本模板采用移动邮箱友好的单列 table 布局，不复制 Rails 模板代码。

额外提供：截止倒计时、正式截止与停止提交的区分、个人计划、过时来源说明、规则与状态说明，以及摘要中逐条保留的完整信息。

不照抄上游的邮件回复回写承诺：本项目没有入站邮箱处理器。外站图片和跟踪像素不自动加载；脚本、危险链接、含临时登录/下载凭据的 href 被剔除。具体成绩仍遵守 `score_in_email`，默认不展示。

富文本和作者/附件补充信息保存在私有 `_email` 元数据中，不参与业务事件差异，避免升级模板时把已有内容重新当作老师发布的更新。该元数据不随源码发布。
