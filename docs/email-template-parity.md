# 邮件模板对照

参考固定 Canvas LMS commit `1c9f0bb8013ed69c4f2efe11fd483025469b7e6c` 的 `app/messages/`：

| 上游模板 | 保留的可见信息 | 本服务补充 |
|---|---|---|
| `_layout.email.html.erb` | 白底、600px 单列、简洁文字链接页脚、移动端字号和旧 Outlook 布局思路 | 个人服务文字标识、清晰的来源/发现/生成时间，详细信息保留 |
| `assignment_created.email.*` / `assignment_changed.email.*` | 课程、作业名称、变更说明、截止或未设日期、查看入口 | 完整任务说明、停止提交/开放时间、允许尝试次数、锁定说明、提交状态与规则说明 |
| `upcoming_assignment_alert.email.*` | 任务、正式截止、查看入口 | 剩余时间、停止提交提醒、最近同步与补偿说明 |
| `assignment_graded.email.*` | 课程、作业标题、成绩已可见说明、作业入口 | 得分/满分和变化前后值使用同一学生可见成绩；隐藏成绩不展示；评分量表按评分项名称、分值和评级展示 |
| `assignment_due_date_changed.email.*` | 课程、任务、调整后的截止或未设置日期 | 调整前后对比、停止提交/开放时间、重新生成提醒计划 |
| `assignment_submitted.email.*` | 提交说明、对应任务/提交入口 | 最近同步、提交时间、重做和豁免状态 |
| `new_announcement.email.*` | 完整标题、正文、简单格式与表格、附件名称/大小/入口 | API 可见作者、正文修改前后对比、发现时间、通知规则、管理入口 |
| `new_file_added.email.*` | 文件名、文件大小、课程、文件入口 | 文件变更详情、Canvas 上传/创建及修改/更新原始时间、发现与邮件生成时间 |
| `submission_comment.email.*` | API 可见的作者姓名/邮箱/资料与头像入口、反馈正文、媒体提示、附件及本人提交入口 | 反馈创建/编辑时间、同步与发现时间、规则来源 |

在 API 实际可见和用户隐私设置允许的范围内保留对应信息；无法读取的信息不编造。独立 Jinja2 HTML/纯文本模板采用移动邮箱友好的单列 table 布局，不复制 Rails 模板代码。

额外提供：截止倒计时、正式截止与停止提交的区分、个人计划、过时来源说明、规则与状态说明，以及摘要中逐条保留的完整信息。

同轮同课程的多个作业与关联提交/学习计划、文件与模块入口统一为一封“课程更新”邮件，事件不丢弃。关联变化放在对应事项下，每项仍保留完整内容、时间、状态、成绩和入口；批次开头不展示首项成绩。邮件正文完整保留标题，仅邮件主题限制长度。正文修改显示纯文本的“修改前”和“修改后”。邮件只在文件事项说明上传时间，在作业或提交事项说明提交状态；每封邮件仅在页脚提示一次非官方服务和回复不会发给老师。

作业从完整列表消失时，邮件说明可能被撤回或删除、提醒已取消，以及最后一次看到作业的时间；重新出现时说明提醒按当前规则恢复。提交状态变化列出缺交、迟交、豁免及扣分的前后值。日程展示起止时间、地点及地址；个人待办展示日期和详情。

按项目要求不支持邮件回复回写 Canvas。外站图片和跟踪像素不自动加载；脚本和危险链接被剔除。Canvas 站内正文链接去掉临时签名等敏感参数，但保留路径、非敏感查询参数及锚点；站外含凭据的链接被剔除。

富文本和作者等邮件补充信息保存在私有 `_email` 元数据中。安全的站内正文链接、附件编号/名称/大小和提交反馈的可见变化也参与业务差异，不保存附件的临时下载地址。

正文图片的稳定 Canvas 文件引用独立保存在 `content_images` 中，参与业务差异；首次为旧快照补齐基线时不触发历史重发。后续图片引用变化可检测，不能据此保证检测同一地址、无元数据变化的像素替换。

## 当前实现范围

- HTML 按官方白底单列风格重新实现，补充 MSO 条件表格、Outlook.com/Hotmail 的 ExternalClass 处理、620px 以下字号与边距调整。提醒详情没有删减。
- 正文使用自动文字方向，支持中英文及 RTL 内容混排；通知文案仍为中文，没有宣称已完成整个系统的多语言翻译。
- 公告、讨论、回复和站内信展示 API 实际返回且可见的作者姓名；不展示隐藏/匿名作者的身份。反馈也可展示 API 可见的作者邮箱、资料和头像入口。头像提供安全链接，不自动加载远程图片。媒体提供类型/名称提示及 Canvas 查看入口，不外发媒体鉴权 URL。
- 任务正文和提交反馈中的 Canvas 文件图片按原文位置作为 CID 内嵌附件展示，纯文本邮件保留图片名称和稳定链接；认证信息及签名参数不外发。图片不可用或超限会说明并保留 Canvas 入口，即使正文只有图片也不留空白。外站跟踪图片不自动读取。
- 只有来源真实提供时才展示文件源时间；缺失/无效值明确提示，不用系统发现时间冒充上传时间。
- 来源时间和仅用于呈现的作者元数据不参与事件差异判定，升级后不会将这些补充信息重发。
- 验证覆盖 HTML 与纯文本、桌面和手机宽度预览、目标邮箱实际入箱。兼容标记已测试，但未声称所有 Outlook 版本均已实机验收。
