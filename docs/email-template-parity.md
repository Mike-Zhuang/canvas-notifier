# 邮件模板对照

参考固定 Canvas LMS commit `1c9f0bb8013ed69c4f2efe11fd483025469b7e6c` 的 `app/messages/`：

| 上游模板 | 保留的可见信息 | 本服务补充 |
|---|---|---|
| `_layout.email.html.erb` | 白底、600px 单列、简洁文字链接页脚、移动端字号和旧 Outlook 布局思路 | 个人服务文字标识、清晰的来源/发现/生成时间，详细信息保留 |
| `assignment_created.email.*` / `assignment_changed.email.*` | 课程、作业名称、变更说明、截止或未设日期、查看入口 | 完整任务说明、停止提交/开放时间、提交状态、规则说明 |
| `upcoming_assignment_alert.email.*` | 任务、正式截止、查看入口 | 剩余时间、停止提交提醒、最近同步与补偿说明 |
| `assignment_graded.email.*` | 课程、作业标题、成绩已可见说明、作业入口 | 成绩变化前后值（受隐私开关控制）、满分、提交状态、同步时间 |
| `assignment_due_date_changed.email.*` | 课程、任务、调整后的截止或未设置日期 | 调整前后对比、停止提交/开放时间、重新生成提醒计划 |
| `assignment_submitted.email.*` | 提交说明、对应任务/提交入口 | 最近同步、提交时间、重做和豁免状态 |
| `new_announcement.email.*` | 标题、正文、简单格式与表格、附件名称/大小/入口 | 发现时间、通知规则、管理入口 |
| `new_file_added.email.*` | 文件名、文件大小、课程、文件入口 | 文件变更详情、Canvas 上传/创建及修改/更新原始时间、发现与邮件生成时间 |
| `submission_comment.email.*` | API 可见的作者姓名/邮箱/资料与头像入口、反馈正文、媒体提示、附件及本人提交入口 | 反馈创建/编辑时间、同步与发现时间、规则来源 |

在 API 实际可见和用户隐私设置允许的范围内保留对应信息；无法读取的信息不编造。独立 Jinja2 HTML/纯文本模板采用移动邮箱友好的单列 table 布局，不复制 Rails 模板代码。

额外提供：截止倒计时、正式截止与停止提交的区分、个人计划、过时来源说明、规则与状态说明，以及摘要中逐条保留的完整信息。

按项目要求不支持邮件回复回写 Canvas，也不展示可直接回复老师的承诺。外站图片和跟踪像素不自动加载；脚本、危险链接、含临时登录/下载凭据的 href 被剔除。具体成绩仍遵守 `score_in_email`，默认不展示。

富文本和作者/附件补充信息保存在私有 `_email` 元数据中，不参与业务事件差异，避免升级模板时把已有内容重新当作老师发布的更新。该元数据不随源码发布。

## 当前实现范围

- HTML 按官方白底单列风格重新实现，补充 MSO 条件表格、Outlook.com/Hotmail 的 ExternalClass 处理、620px 以下字号与边距调整。提醒详情没有删减。
- 正文使用自动文字方向，支持中英文及 RTL 内容混排；通知文案仍为中文，没有宣称已完成整个系统的多语言翻译。
- 作者邮箱、资料和头像仅使用 API 实际返回且可见的字段；隐藏/匿名作者不显示联系方式。头像提供安全链接，不自动加载远程图片。媒体提供类型/名称提示及 Canvas 查看入口，不外发媒体鉴权 URL。
- 只有来源真实提供时才展示文件源时间；缺失/无效值明确提示，不用系统发现时间冒充上传时间。
- 来源时间和反馈元数据加入 `_email`，不参与业务差异判定，升级后不会将历史内容重发。
- 验证覆盖 HTML 与纯文本、桌面和手机宽度预览、目标邮箱实际入箱。兼容标记已测试，但未声称所有 Outlook 版本均已实机验收。
